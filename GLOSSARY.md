# Kanban

The language used to describe work and its organization on the board.

## Language

**Board**:
A view of work organized into columns.
_Avoid_: Project, workspace

**Column**:
A named grouping of tasks on a board.
_Avoid_: Lane, list, stage, status

**Task**:
A work item represented by a title and an optional description.
_Avoid_: Item, ticket, issue, story

**Card**:
The visual representation of a task on the board.
_Avoid_: Tile, note
